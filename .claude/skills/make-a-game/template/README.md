## How to play

- **Main knob** (right knob, or left knob in left-handed mode): move the paddle
- **Tilt:** the wind pushes the stars
- **Click either knob:** play again after game over
- **Hold either knob:** pause menu (Resume / Restart / Quit)

## Development

Keep this game's files here. Run `python3 tools/tg.py test` and
`python3 tools/tg.py build` from the repository root. Update the controls and
credit above when you turn this starter into your own game.
