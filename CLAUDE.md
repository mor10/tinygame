# Claude Code compatibility

For game creation, fixes or changes, automatically use `make-a-tinygame`
(`.agents/skills/make-a-tinygame/SKILL.md`) if it is not already active. If skill invocation
is unavailable, read that file directly. It routes to the shared [cart guide](AGENTS.md).

For engine, simulator, tooling, firmware, hardware and implementation history, read
[docs/development.md](docs/development.md). All detailed developer notes live there;
this file exists only to preserve Claude Code's repository instruction discovery.
