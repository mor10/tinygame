# Making a TinyGame cart

Read `AGENTS.md` at the repository root and follow its cart-making workflow.
It is the single source of game guidance: required API and template reading,
the `./tg` write/check/look/fix loop, control conventions and hardware boundaries.
Do not invoke this skill again when that file points back here; it is already active.

Resolve all paths and run all commands from the repository root, not this skill directory.
For engine, firmware or tooling work unrelated to a cart, use `docs/development.md` and `README.md`
instead.
